# 混合示意与实物有机融入指南

本指南适用于所有工程与学术汇报示意图。核心目标是**在完整保留原版克制 2.5D 工程插画美感与统一空间叙事的前提下**，通过“真实实物原位替换 / 圆形放大视窗 + 同色系定量科学图浮卡 + 极简可编辑标注”大幅提升工程真实感与信息密度——**严禁把整张图退化成几张生硬矩形照片的扁平拼贴**。

## 1. 融合方式与真实素材获取优先级

先确定干净统一的 2.5D 工程情景骨架，再按以下优先级选取核心节点的真实视觉锚点，并用最自然的方式融入画风：

1. **有机融入三手法（拒绝生硬拼贴）**：
   - **透明抠图原位替换**：将真实卫星、真实地球等做无损透明抠图后，按原 2.5D 视角与倾角直接替换概念图形，让信号波束、轨道弧线自然衔接；
   - **圆形硬件放大视窗**：对传感器 PCB、车载感知平台等带背景的实拍图，裁切紧凑主体装入白边细环微阴影圆形视窗，以细虚线引出指向 2.5D 场景中的对应部件，视觉轻量且不打断整体空间感；
   - **同色系定量浮卡**：将本人论文实测图或 `nav-sciplot` 误差对比曲线（配色与 2.5D 数据流主色一致）装入白底细边框微阴影浮卡，通过细虚线锚点直连融合平台或定位结果节点。
2. **用户/团队一手素材优先**：
   - 先检查目标 `.pptx` 内嵌图片（`ppt/media/`）及工作目录中已有的实物照、界面图、论文 PDF；
   - 如涉及作者/团队已发表论文（如 *Journal of Geodesy*、*GPS Solutions*、*Satellite Navigation* 等），可通过 Crossref / OpenAlex 检索其代表作中的核心实测结果图，优先展示本人成果而非第三方泛化示意波形。
3. **权威公开实物与科学图（Public Domain / CC-BY）**：
   - **全球尺度**：优先使用 NASA Blue Marble 等真实东半球/目标区域地球实拍（黑底地球便于无损圆形抠图，保留自然大气蓝边）；
   - **空间/硬件实物**：优先使用公开授权的真实卫星、接收机、惯导、激光雷达等传感器与载体实物照；
   - **环境/地球物理观测场**：优先使用公开权威卫星观测或实测分布场，替代卡通云朵与抽象几何色块。
4. **透明抠图、严禁露馅字样与单子图质检**：
   - 纯黑/纯白底实物图使用连通域泛洪抠图并清理支架间封闭黑/白残块，边缘做 1–2 px 抗锯齿羽化；
   - **严禁在图件内部标题、图例或标注中写入“模拟示例”“示意数据”“Demo”“Placeholder”等业余字样**；
   - 从多子图论文图（如 2×1 或 3×3 组图）中提取单个子图时，**必须检测相邻子图刻度线与轴数字的像素边界**，彻底清除残缺的半个数字或上/下子图边框，再把原图图例无遮挡地移入子图空白处（不得改动原数据柱/曲线）。

## 2. 构图与文字减法清单

制作前逐项核对，任一项不通过则先调整布局再渲染：

| 核查项 | 合格标准 | 常见反例 |
| --- | --- | --- |
| **空间尺度** | 主题含“全球/广域”时，呈现真实地球、全球轨道环与跨洲监测节点 | 讲“全球高精度导航”却画成一小块局部草地 |
| **实物锚点** | 实物/实测图精准对应核心工作（如传感器硬件、大气/地球物理场、核心性能曲线） | 塞入与核心创新弱相关的常规外围设备照片 |
| **页面去重** | 与同页 PPT 正文交叉比对，不重复写正文已展开的句子 | 卡片内堆砌多行小字原理说明 |
| **图意释义** | 本人/团队实测图配一句直白中文释义（如“蓝：原模型 / 红：改进模型”） | 机械贴上“(Author et al., 2025)”或“(NASA)”尾注 |
| **连线压字** | 表达因果/辅助关系的短词直接压在对应连线上，视觉流向连续 | 关系标签悬空漂在箭头旁边或压在暗色背景上 |
| **终端具象** | 定位/应用结果用轻量具象载具（如带天线车辆）+ 短词呈现 | 纯文字胶囊，或在情景图中又硬塞一套复杂用户误差图 |

## 3. 主次与辅助关系的视觉语法

- **主线模块**：使用 PPT 主强调色（如深红或深蓝）作为顶栏与边框色，占更大版面，以实线粗箭头串联核心实物、核心引擎与用户终端。
- **辅助模块**：使用低饱和冷色（如青蓝 `#1E7285`）线框/浅色卡片，面积小于主线；先指向其作用的物理/感知环节，再由**虚线/汇聚箭头直接接入主线核心平台**，并在该连线上直接放置简短关系标签。

## 4. PPTX 版式提取与双轨交付

当用户提供 `.pptx` 时，按以下闭环执行：

1. **自动提取版式**：运行 `scripts/inspect_pptx_layout.py <file.pptx>`，记录：
   - 幻灯片宽高（cm）；
   - 目标图片/占位框的精确 `x, y, w, h`（cm）及宽高比（绘图画布严格按此比例设置，误差 < 0.5%）；
   - 原页字体（如 `微软雅黑`）与主题主色（如 `#C00000`）；
   - 同页全部已有文字（用于文字去重）。
2. **不覆写原文件，双轨输出**：
   - `*_可编辑版.pptx`：原位放入无文字底图，用 `python-pptx` 按像素-EMU 线性映射叠加原生圆角形状、文本框（显式写入东亚字体 `a:ea`）与虚线连接器；
   - `*_一体化图版.pptx`：原位放入高分辨率一体化成品 PNG，确保在无对应字体或不同版本 PowerPoint 上放映零漂移。
3. **实景尺寸视觉验收**：在输出前将成品图按目标槽位像素尺寸贴回原页截图（或用 LibreOffice 渲染 PPT 页面）打开检查，确认在全屏放映和缩略尺寸下均无截断、无重叠、主次一目了然。
